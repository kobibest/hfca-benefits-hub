# מרכז ההטבות — התאחדות יועצי המשכנתאות

אתר ההטבות הרשמי לחברי **התאחדות יועצי המשכנתאות**, מטעם הוועדה הכלכלית.
ריכוז ההנחות, השירותים והמבצעים הבלעדיים לחברי ההתאחדות במקום אחד.

🔗 **אתר ארגון:** [hfca.org.il](https://hfca.org.il/)

## תכונות

- 20 הטבות בלעדיות עם סינון לפי קטגוריה וחיפוש חי
- חזון הוועדה הכלכלית וחברי הוועדה
- טופס "הצעת הטבה חדשה" לוועדה
- עיצוב dark-first יוקרתי, RTL מלא, רספונסיבי ונגיש
- מצב בהיר/כהה, אנימציות מתוזמרות, ו-`prefers-reduced-motion`
- פאנל ניהול עם **לוג מלא של כל שינוי** (הוספה / עריכה / מחיקה / שחזור) ו**מעקב צפיות מדויק** לכל הטבה

## ניהול, לוג שינויים ומעקב צפיות

בפאנל הניהול (קישור "ניהול" בתחתית האתר) שלושה טאבים:

- **ניהול הטבות** — הוספה, עריכה ומחיקה של הטבות (מצב הרשימה נשמר ב-`localStorage` של הדפדפן).
- **לוג שינויים** — רישום מלא ובלתי-נמחק של כל פעולת ניהול (מי, מתי, איזו הטבה ואיזו פעולה), כולל תצלום "לפני/אחרי".
- **צפיות בהטבות** — מספר הצפיות המדויק בכל הטבה, מצטבר מכלל המבקרים. צפייה נספרת פעם אחת לכל הטבה בכל session בדפדפן.

הלוג והצפיות נשמרים ב-**Supabase** (פרויקט `HFCA`), בטבלאות ייעודיות
(`benefits_hub_change_log`, `benefits_hub_views`) הנפרדות משאר מערכת ההתאחדות.
הספירה מתבצעת דרך פונקציית RPC אטומית (`increment_benefit_view`).

> הערה על אבטחה: הניהול הוא לקוח-בלבד (סיסמה בקוד), ולכן כתיבת הלוג וספירת הצפיות נעשות עם מפתח ה-`anon` הציבורי ומדיניות RLS מתירנית — בהתאם לאופי הסטטי של האתר. אין בטבלאות אלו מידע רגיש.

## טכנולוגיה

אתר סטטי בקובץ HTML יחיד עצמאי (Vanilla HTML/CSS/JS) — ללא תלויות build.
פריסה כסטטי ב-Vercel. לוג השינויים ומעקב הצפיות משתמשים ב-Supabase (REST/RPC) ישירות מהדפדפן.

## פיתוח מקומי

פשוט פותחים את `index.html` בדפדפן, או:

```bash
python -m http.server 5577
# http://localhost:5577
```
