# מרכז ההטבות — התאחדות יועצי המשכנתאות

אתר ההטבות הרשמי לחברי **התאחדות יועצי המשכנתאות**, מטעם הוועדה הכלכלית.
ריכוז ההנחות, השירותים והמבצעים הבלעדיים לחברי ההתאחדות במקום אחד.

🔗 **אתר ארגון:** [hfca.org.il](https://hfca.org.il/)

## תכונות

- 20 הטבות בלעדיות עם סינון לפי קטגוריה וחיפוש חי
- חזון הוועדה הכלכלית וחברי הוועדה
- טופס "הצעת הטבה חדשה" לוועדה
- עיצוב dark-first יוקרתי, RTL מלא, רספונסיבי ונגיש
- מצב בהיר/כהה, אנימציות מתוזמרות, ו-`prefers-reduced-motion`
- **כל הנתונים ב-Supabase** — הטבות, משתמשי ניהול, לוג שינויים ומעקב צפיות
- פאנל ניהול עם התחברות אמיתית, **לוג מלא של כל שינוי** (הוספה / עריכה / מחיקה / שחזור) ו**מעקב צפיות מדויק** לכל הטבה

## נתונים ואחסון (Supabase)

כל הנתונים חיים בפרויקט **Supabase** בשם `HFCA`, בטבלאות ייעודיות הנפרדות משאר מערכת ההתאחדות:

| טבלה | תוכן |
|------|------|
| `benefits_hub_benefits` | ההטבות עצמן (שם, קטגוריה, תגית, תיאור, קישורים, סדר) |
| `benefits_hub_change_log` | לוג מלא של כל פעולת ניהול (פעולה, הטבה, מנהל, תאריך, תצלום לפני/אחרי) |
| `benefits_hub_views` | מונה צפיות לכל הטבה, מצטבר מכלל המבקרים |

הצפיות נספרות דרך פונקציית RPC אטומית (`increment_benefit_view`). האתר קורא את ההטבות
ישירות מ-Supabase (REST); אם השרת אינו זמין, מוצגת רשימת ברירת-מחדל מובנית עד להתחברות.

## ניהול (התחברות + טאבים)

הכניסה לניהול (קישור "ניהול" בתחתית האתר) מבוססת **Supabase Auth** (אימייל + סיסמה) —
אין יותר סיסמה קשיחה בקוד. שלושה טאבים:

- **ניהול הטבות** — הוספה, עריכה ומחיקה. כל שינוי נכתב ישירות ל-Supabase.
- **לוג שינויים** — רישום מלא של כל פעולת ניהול, כולל שם המנהל שביצע.
- **צפיות בהטבות** — מספר הצפיות המדויק בכל הטבה (צפייה נספרת פעם אחת לכל הטבה בכל session).

### הרשאות (RLS)

- **הטבות** — קריאה פתוחה לכולם (הצגת האתר); כתיבה רק למנהל מחובר.
- **לוג שינויים / צפיות** — קריאה וכתיבה רק למנהל מחובר. הגדלת מונה הצפיות פתוחה למבקרים אנונימיים דרך ה-RPC בלבד.

הוספת/שינוי משתמשי ניהול נעשית בלוח הבקרה של Supabase (Authentication → Users).

## טכנולוגיה

אתר בקובץ HTML יחיד (Vanilla HTML/CSS/JS) — ללא תלויות build ו-ללא שלב bundling.
פריסה כסטטי ב-Vercel. השכבה הדינמית (הטבות, התחברות, לוג, צפיות) מדברת עם Supabase
(REST / RPC / Auth) ישירות מהדפדפן.

## פיתוח מקומי

פשוט פותחים את `index.html` בדפדפן, או:

```bash
python -m http.server 5577
# http://localhost:5577
```
