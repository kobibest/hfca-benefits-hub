# מרכז ההטבות — התאחדות יועצי המשכנתאות

אתר ההטבות הרשמי לחברי **התאחדות יועצי המשכנתאות**, מטעם הוועדה הכלכלית.
ריכוז ההנחות, השירותים והמבצעים הבלעדיים לחברי ההתאחדות במקום אחד.

🔗 **אתר ארגון:** [hfca.org.il](https://hfca.org.il/)

## תכונות

- כניסה לאתר בתעודת זהות (חברי ההתאחדות בלבד), מוכנה לחיבור ל-API החברות
- 20 הטבות בלעדיות עם סינון לפי קטגוריה וחיפוש חי
- קובץ מצורף (תמונה או PDF) לכל הטבה — המנהל מעלה בפאנל הניהול, והחברים מורידים מכרטיס ההטבה
- חזון הוועדה הכלכלית וחברי הוועדה
- טופס "הצעת הטבה חדשה" לוועדה
- עיצוב dark-first יוקרתי, RTL מלא, רספונסיבי ונגיש
- מצב בהיר/כהה, אנימציות מתוזמרות, ו-`prefers-reduced-motion`
- **כל הנתונים ב-Supabase** — הטבות, משתמשי ניהול, לוג שינויים ומעקב צפיות
- פאנל ניהול עם התחברות אמיתית, **לוג מלא של כל שינוי** (הוספה / עריכה / מחיקה / שחזור) ו**מעקב צפיות מדויק** לכל הטבה

## כניסה לאתר (תעודת זהות)

האתר סגור למבקרים ונפתח רק לאחר הזנת **מספר תעודת זהות** של חבר התאחדות.
מסך הכניסה מוצג לפני כל תוכן האתר, והכניסה נשמרת בדפדפן ל-30 יום (יציאה — התג שבתפריט העליון).

**מצב זמני:** כל עוד ה-API של ההתאחדות לא חובר, מאושרת רק תעודת הזהות **123456789**.

### חיבור ה-API

כל לוגיקת הבדיקה יושבת בבלוק אחד ב-`index.html` (חפשו `MEMBER GATE`).
כדי לעבור לבדיקה אמיתית מול השרת, ממלאים את `MEMBER_API` — ואין צורך בשינוי נוסף בקוד:

```js
const MEMBER_API={
  url:'https://api.hfca.org.il/members/verify', // ריק = מצב זמני
  method:'POST',        // 'POST' או 'GET'
  key:'',               // אופציונלי — נשלח בכותרת x-api-key
  idParam:'id',         // שם השדה שבו נשלחת תעודת הזהות
  parse:(data,res)=>({ok:…,name:…})            // תרגום תשובת השרת
};
```

- `parse` מתרגם את תשובת השרת ל-`{ok,name}`. ברירת המחדל מזהה את השדות
  `ok / valid / is_member / exists / active` ואת `name / full_name / member_name`;
  אם התשובה 200 ואין בה אף אחד מהשדות הללו — היא נחשבת לאישור.
- סטטוס `404` מהשרת = "אינו חבר" (הודעה למשתמש), כל שאר השגיאות = "שגיאה זמנית, נסו שוב".
- אחרי החיבור אפשר למחוק את `TEMP_ALLOWED_IDS` (רשימת ת"ז הבדיקה הזמנית).

> שימו לב: זהו שער בצד הלקוח על אתר סטטי — הוא מסתיר את האתר ממבקרים מזדמנים,
> אך אינו מונע גישה לתוכן ה-HTML עצמו. הגנה ממשית תדרוש הגשת התוכן מהשרת לאחר אימות.
> מנהל מחובר (Supabase Auth) נכנס לאתר גם בלי תעודת זהות, ומסך הכניסה מאפשר מעבר ישיר לכניסת מנהל.

## נתונים ואחסון (Supabase)

כל הנתונים חיים בפרויקט **Supabase** ייעודי ונפרד בשם `HFCA Benefits Hub`
(ref `kshmxhkdysuhxyigsett`) — פרויקט עצמאי לחלוטין, שאינו חולק דבר עם מערכת ההתאחדות הפנימית
(משתמשי הניהול שלו נפרדים, וכך גם ה-DB):

| טבלה | תוכן |
|------|------|
| `benefits_hub_benefits` | ההטבות עצמן (שם, קטגוריה, תגית, תיאור, קישורים, סדר, קובץ מצורף) |
| `benefits_hub_change_log` | לוג מלא של כל פעולת ניהול (פעולה, הטבה, מנהל, תאריך, תצלום לפני/אחרי) |
| `benefits_hub_views` | מונה צפיות לכל הטבה, מצטבר מכלל המבקרים |

הקבצים המצורפים נשמרים בדלי אחסון ציבורי בשם `benefit-files` (עד 10MB לקובץ, PNG/JPG/WEBP/GIF/SVG או PDF),
וההטבה מצביעה אליהם בעמודות `file_url`, `file_name`, `file_path` ו-`file_type`.

הצפיות נספרות דרך פונקציית RPC אטומית (`increment_benefit_view`). האתר קורא את ההטבות
ישירות מ-Supabase (REST); אם השרת אינו זמין, מוצגת רשימת ברירת-מחדל מובנית עד להתחברות.

## ניהול (התחברות + טאבים)

הכניסה לניהול (קישור "ניהול" בתחתית האתר) מבוססת **Supabase Auth** (שם משתמש + סיסמה) —
אין יותר סיסמה קשיחה בקוד. שם המשתמש מתורגם לכתובת האימייל של החשבון בצד השרת, דרך
פונקציית RPC (`benefits_hub_admin_email`) שמחפשת התאמה לשדה `username` שב-metadata של המשתמש,
ואם אין — לחלק שלפני ה-`@` בכתובת האימייל. אפשר להזין גם אימייל מלא. שלושה טאבים:

- **ניהול הטבות** — הוספה, עריכה ומחיקה. כל שינוי נכתב ישירות ל-Supabase.
  בטופס ההטבה אפשר לצרף **קובץ אחד** (תמונה או PDF): הקובץ מועלה לדלי `benefit-files`,
  מוצג לעריכה עם אפשרות הסרה, ומוחלף/נמחק מהאחסון אוטומטית כשמחליפים אותו, מסירים אותו,
  מוחקים את ההטבה או משחזרים ברירת מחדל. בכרטיס ההטבה נוסף כפתור הורדה, ובדף ההטבה
  מוצג המסמך המצורף (תמונות עם תצוגה מקדימה).
- **לוג שינויים** — רישום מלא של כל פעולת ניהול, כולל שם המנהל שביצע.
- **צפיות בהטבות** — מספר הצפיות המדויק בכל הטבה (צפייה נספרת פעם אחת לכל הטבה בכל session).

### הרשאות (RLS)

- **הטבות** — קריאה פתוחה לכולם (הצגת האתר); כתיבה רק למנהל מחובר.
- **קבצים מצורפים** (`benefit-files`) — הורדה פתוחה לכולם; העלאה, החלפה ומחיקה רק למנהל מחובר.
- **לוג שינויים / צפיות** — קריאה וכתיבה רק למנהל מחובר. הגדלת מונה הצפיות פתוחה למבקרים אנונימיים דרך ה-RPC בלבד.

הוספת/שינוי משתמשי ניהול נעשית בלוח הבקרה של Supabase (Authentication → Users).
לקביעת שם משתמש לחשבון, מוסיפים ל-User Metadata שלו שדה `username` (למשל `"username": "hfca"`).

## טכנולוגיה

אתר בקובץ HTML יחיד (Vanilla HTML/CSS/JS) — ללא תלויות build ו-ללא שלב bundling.
פריסה כסטטי ב-Vercel. השכבה הדינמית (הטבות, התחברות, לוג, צפיות) מדברת עם Supabase
(REST / RPC / Auth) ישירות מהדפדפן.

## פיתוח מקומי

פשוט פותחים את `index.html` בדפדפן, או:

```bash
python -m http.server 5577
# http://localhost:5577
```
